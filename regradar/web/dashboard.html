              CI/CD Pipeline & Webhook Setup Guide
            

            
Instructions and pipeline configurations for hooking your remote repository to RegRadar.

          

          

            

              
              
            

            
          

        


        
        

          
          

            

              
GitHub Payload URL

              

                
                
              

              

                In GitHub → Settings → Webhooks → Add webhook. Content type: application/json.
              

            


            
            

              

                
Webhook Security & Gating

                

                  

                    Payload Signature:
                    HMAC SHA-256
                  

                  

                    Merge Policy:
                    Mandatory Operator Sign-Off
                  

                  

                    Deletion Invariant:
                    0 destructions allowed
                  

                

              

              

                Dry-run plan diff must contain 0 deletions before staging.
              

            

          


          
          

            

              
Step-by-Step GitHub Setup

              
    
                
  1. Open your repository on GitHub and navigate to Settings > Webhooks > Add webhook.
    2. 
                
  2. Paste the Payload URL above into the Payload URL field.
    3. 
                
  3. Select application/json as the Content type.
    4. 
                
  4. Enter your secret matching the REGRADAR_GITHUB_WEBHOOK_SECRET environment variable.
    5. 
                
  5. Under events, choose Let me select individual events and check Pull requests and Pushes.
    6. 
                
  6. Save the webhook. Incoming pull requests will appear in the staging queue.
    7. 
              

            


            

              

                
.github/workflows/regradar-gate.yml

                
              

              
name: RegRadar Zero-Destruction Gate
on:
  pull_request:
    branches: [ main, master ]

jobs:
  regradar-invariant-audit:
    runs-on: ubuntu-latest
    steps:
      - name: Checkout Code
        uses: actions/checkout@v4

      - name: Setup OpenTofu
        uses: opentofu/setup-opentofu@v1

      - name: Generate Plan Diff
        run: |
          tofu init
          tofu plan -out=plan.tfplan
          tofu show -json plan.tfplan > plan.json

      - name: Dispatch Plan to RegRadar Gate
        env:
          REGRADAR_URL: ${{ secrets.REGRADAR_URL }}
        run: |
          curl -s -X POST "${REGRADAR_URL}/api/webhooks/github" \
            -H "Content-Type: application/json" \
            -H "X-GitHub-Event: pull_request" \
            -d @plan.json

            

          

        


        
        

          
          

            

              
GitLab Webhook URL

              

                
                
              

              

                In GitLab → Settings → Webhooks → Add new webhook. Trigger on: Merge requests events & Push events.
              

            


            

              

                
GitLab Authentication

                

                  

                    Header:
                    X-Gitlab-Token
                  

                  

                    Gate Mode:
                    Invariant Checked
                  

                

              

              

                Posts audit note back to GitLab MR automatically.
              

            

          


          
          

            

              
Step-by-Step GitLab Setup

              
    
                
  1. Open your GitLab project and navigate to Settings > Webhooks > Add new webhook.
    2. 
                
  2. Paste the GitLab Webhook URL into the URL field.
    3. 
                
  3. Enter the Secret token matching your REGRADAR_GITLAB_WEBHOOK_SECRET.
    4. 
                
  4. Under Trigger, check Merge requests events and Push events.
    5. 
                
  5. Click Add webhook to save.
    6. 
                
  6. Add the CI configuration below to your project as .gitlab-ci.yml.
    7. 
              

            


            

              

                
.gitlab-ci.yml

                
              

              
stages:
  - governance

regradar-zero-destruction-gate:
  stage: governance
  image: ghcr.io/opentofu/opentofu:latest
  rules:
    - if: $CI_PIPELINE_SOURCE == "merge_request_event"
  script:
    - tofu init
    - tofu plan -out=plan.tfplan
    - tofu show -json plan.tfplan > plan.json
    - |
      curl -s -X POST "${REGRADAR_URL}/api/webhooks/gitlab" \
        -H "Content-Type: application/json" \
        -H "X-Gitlab-Event: Merge Request Hook" \
        -H "X-Gitlab-Token: ${REGRADAR_GITLAB_WEBHOOK_SECRET}" \
        -d @plan.json
