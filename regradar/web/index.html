System Design

            
Two-gate safety design

            
Two safety checks run before and after code generation to stop destructive changes.

          


          
          

            
            
          

        


        
        

          
        


        
        

          

flowchart TD
    TF["Terraform Source
Infrastructure files"] --> CHK["Checkov Scanner
Finds policy issues"]
    TF --> AST["Syntax Parser
Reads resource tree"]
    AST --> DAG["Dependency Graph
Maps relationships"]
    CHK --> G1{"Gate 1: Dependency Check
Blast radius evaluation"}
    DAG --> G1
    G1 -- "Core resource" --> ESC["Human Review
Needs operator approval"]
    G1 -- "Safe leaf resource" --> SWARM["Multi-Agent Swarm
Plans and writes patch"]
    SWARM --> G2{"Gate 2: Sandbox Test
Dry-run plan diff check"}
    G2 -- "Deletions found" --> RETRY["Rejected
Sent back to agents"]
    RETRY --> SWARM
    G2 -- "No deletions" --> PR["Safe Pull Request
Ready for review"]
